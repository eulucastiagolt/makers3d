# Makers 3D v0.2.0

- Interface desktop baseada nas telas do Calc3D.
- Calculadoras de impressão 3D, Shopee, TikTok Shop e Mercado Livre.
- Históricos pesquisáveis, edição, exportações por orçamento e transferência de custos entre calculadoras.
- Backups locais em JSON com importação compatível com a versão anterior.
